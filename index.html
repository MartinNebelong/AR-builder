Deploy →
Drag files in, push them straight to this Pages site. Token is held in the page's memory only and cleared when the tab closes.
deploy.html
Every page is a single self-contained .html file — no build step, no bundler. The AR modes need HTTPS and a WebXR-capable browser (Chrome on Android); opening a file from disk over file:// will not start a session — serve it over HTTPS or use the Launcher.
